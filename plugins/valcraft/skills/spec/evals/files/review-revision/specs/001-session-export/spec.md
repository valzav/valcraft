# Session export

## Sources

- `docs/session-export-prd.md`

## Summary

Export session activity as CSV.

## Functional requirements

- FR-001: An administrator MUST be able to export session activity as CSV.
- FR-002: The CSV MUST label every timestamp as UTC.

## Acceptance criteria

- [ ] AC-001: The export contains the selected sessions.
- [ ] AC-002: Every timestamp column heading and value identifies UTC.
