# linkbox — product brief

## Problem

People need a small local tool for saving and finding useful links.

## Users

The primary user is the person running the CLI.

## MVP outcome

Save one link and find it later by searching its title.

## Constraints

Use Node 22, commander, SQLite, and the existing `src/store.js` persistence boundary.
