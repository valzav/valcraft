# PRD: Workspace invitations

## Problem

The only way to add a teammate today is for an admin to share their own credentials, which we have told customers never to do.

## What we want

An admin invites a teammate by email address. The teammate follows the invitation and joins the workspace. An invitation is single-use: once accepted it cannot be reused, so a forwarded invitation link does not let a second person in.

## Out of scope

- Bulk invitations or CSV upload.
- Role selection at invite time; invited members get the default role.
