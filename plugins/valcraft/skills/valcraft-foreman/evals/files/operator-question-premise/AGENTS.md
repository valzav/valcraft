# Agent instructions

## Orientation

- `docs/` contains product context, requirements, and the archive record.
- `specs/` contains canonical feature specifications and quick-task files.
- `src/` contains application code. `tests/` contains automated tests.

## Commands

- Test: `PYTHONPATH=src python3 -m unittest discover -s tests`

## Change discipline

- Reference requirement and task IDs (`FR-`, `AC-`, `T-`, `QT-`) from commits and tests.
