# Agent instructions

## Orientation

- `docs/` contains product context, requirements, and working plans.
- `specs/` contains canonical feature specifications.
- `src/` contains application code. `tests/` contains automated tests.

## Commands

- Test: `PYTHONPATH=src python3 -m unittest discover -s tests`

## Change discipline

- Reference `FR-`, `AC-`, and canonical task identities, `FEAT-NNN/T-XXX` or `Q-NNN/QT-XXX`, from commits, PR titles, and tests.
