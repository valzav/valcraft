# Recurring activity report

## Sources

- `docs/recurring-report-prd.md`

## Summary

Send team leads a weekly workspace activity report.

## Functional requirements

- FR-001: A team lead MUST be able to schedule a weekly activity report.
- FR-002: The system MUST send the report to the lead's verified email address each Monday.

## Acceptance criteria

- [ ] AC-001: A scheduled report arrives at the lead's verified email address on Monday.
