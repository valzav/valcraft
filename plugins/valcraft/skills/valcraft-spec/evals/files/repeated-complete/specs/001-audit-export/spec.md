# Audit export

## Sources

- `docs/audit-export-prd.md`

## Summary

Export account activity for a selected calendar month.

## Functional requirements

- FR-001: An administrator MUST be able to export account activity for one selected calendar month as CSV.

## Acceptance criteria

- [ ] AC-001: The CSV contains activity from the selected month and excludes activity outside it.
