# Legend — product brief

## Problem

Build logs mark each check with a status, and operators misread statuses whose colors look alike.

## Users

Operators who read colored build output in a 24-bit color terminal.

## MVP outcome

An operator runs one command and sees the five statuses, each in its own clearly distinct color.
