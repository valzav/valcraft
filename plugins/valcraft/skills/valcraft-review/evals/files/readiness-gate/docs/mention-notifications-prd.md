# PRD: Mention notifications

## Problem

Members only discover that someone mentioned them by re-reading threads. Mentions meant to pull someone into a decision are missed for days.

## What we want

When a member is mentioned in a comment, they are notified, and they can get from the notification to the comment in one step.

## Open question for the team

We have not decided what happens when someone edits an already-published comment to add a mention that was not there before. Notifying on edit is closer to what the mentioning person expects; notifying only on first publish is simpler and cannot be used to spam someone by repeatedly editing. This needs a product decision before build.

## Out of scope

- Email or push delivery. In-product notifications only for now.
- Mention autocomplete changes.
