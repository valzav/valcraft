# PRD: Game over

## Problem

When the stack reaches the top of the board, Blockfall stops moving without telling the player why.

## What we want

The game ends when a block locks in the top row. While a game is in progress, no game-over panel covers the board. When the game ends, a panel says the game is over and shows the final score.

## Out of scope

- Restarting a game.
- High scores.
